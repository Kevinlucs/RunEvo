# Integrações com relógios — referência visual

Estas telas e logos foram preservados apenas como referência de design para uma
futura fase de integrações **oficiais** com Garmin, COROS, Polar e Amazfit.

Elas não pertencem às rotas do app, não são compiladas pelo Expo e não contêm
autenticação, credenciais, tokens, sincronização ou chamadas de API. Quando os
acessos oficiais forem aprovados, esta referência pode orientar a nova UX.
